This website uses **no cookies** and, apart from the visitor statistics described below, loads **no third-party content** (fonts are served locally). It is hosted on GitHub Pages (GitHub Inc., USA), which processes technically necessary data such as IP addresses in server log files. For visitor statistics it uses GoatCounter, a privacy-friendly service hosted in the EU that sets no cookies, stores no IP addresses and only records aggregated figures (page, referrer, browser, screen width, approximate country). See the [German privacy statement](/datenschutz/) for details.
